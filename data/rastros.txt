# S3-3: el RASTRO de los salones, una decoracion (easter egg) segun como te fue
# en la materia: celebracion si te fue bien, tristeza si te fue mal. Nada
# aparece hasta que pasa el examen de esa materia.
#
# rastro | idEscena | materia | condicion | tipo | x | y | ancho | alto | estilo | nombre | texto
#
#   idEscena:  salon donde queda el rastro (salon_calculo, salon_fisica, laboratorio)
#   materia:   calculo | fisica | programacion (de cual examen depende)
#   condicion: aprobado | reprobado | no_presento | presentado (aprobado o
#              reprobado) | cualquiera (ya paso el examen, se presento o no)
#   tipo y estilo (cada tipo acepta solo algunos estilos):
#     pizarra  -> carita dibujada en la pizarra. estilo: feliz | triste | serio.
#                 "nombre" es el titulo que se escribe al lado (ej. la nota).
#                 Con E se lee el "texto".
#     objeto   -> decoracion suelta. estilo: globos | trofeo | papel | nube.
#                 "nombre" va debajo. Con E se lee el "texto".
#     ambiente -> todo el salon: fiesta (tono calido y confeti) o tristeza
#                 (tono azul y lluvia). x, y, ancho, alto, nombre y texto no
#                 se usan (poner 0 y -).
#     mensaje  -> sale solo, una vez, al entrar al salon. estilo: -  (x, y,
#                 ancho, alto y nombre no se usan: 0 y -).
#   x, y, ancho, alto: en la vista de 640 x 360.
#   texto: \n = salto de linea. Se puede usar {nota}, {materia}, {promedio},
#          {asistencias}, {faltas}, {nota_calculo}, {nota_fisica} y
#          {nota_programacion}.
#
# fase | numero | texto
#   Aviso al empezar la fase 2 o 3 (se desbloquean salones; ver faseMinima en
#   data/escenas.txt). Usa las mismas llaves de arriba.
